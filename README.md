# Colony label review (GitHub Pages)

The click-through review page for disputed colony spots on crowded training
plates, served at https://akashbabu9392.github.io/colony_detector/.
Built by `tools/answer_key.py kit` on the `main` branch. Each reviewer picks
a batch, decides spots, and clicks "Save decisions file"; the returned files
are merged with `answer_key.py from-web`.
